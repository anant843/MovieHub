# 🎬 MovieHub

MovieHub is a Netflix-inspired movie discovery platform built with React, Redux Toolkit, Firebase Authentication, TMDB API, Gemini AI, and Tailwind CSS.

## 🚀 Features

- 🔐 Firebase Authentication
- 🎥 Browse Trending & Popular Movies
- 📺 Watch Movie Trailers
- 🤖 AI-Powered Movie Search using Gemini AI
- ⚡ Redux Toolkit State Management
- 📱 Responsive Design
- 🎨 Netflix-Inspired UI
- 🔄 Real-Time Movie Data from TMDB

## 🛠️ Tech Stack

- React
- Vite
- Redux Toolkit
- Tailwind CSS
- Firebase
- TMDB API
- Gemini AI

## ⚙️ How It Works

1. User logs in using Firebase Authentication.
2. Movie data is fetched from TMDB API.
3. Data is stored in Redux Store.
4. Featured movie is displayed in the Hero Section.
5. Movie categories are rendered dynamically.
6. Gemini AI processes user search queries.
7. Matching movies are displayed to the user.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/anant843/Moviehub.git
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

## 🔑 Environment Variables

Create a `.env` file in the project root:

```env
VITE_TMDB_API_KEY=your_tmdb_api_key
VITE_GEMINI_API_KEY=your_gemini_api_key
```
